A sample command-line application with an entrypoint in `bin/`, library code
in `lib/`, and example unit test in `test/`.
1. ToDo-приложение
Приложение  работает в цикле: показывает меню, ждёть команду и
выполняет её.
2. Хортюнова София ИСП-241
3. Запуск
1) Клонировать репозиторий: `https://github.com/Sofia1-min/Dart_Lab2.git`
2) Перейти в папку: cd lab2_todo
3) Установить зависимости: dart pub get
4) Запустить: dart run
4. Научилась создавать классы, работать с полями, конструкторами
и методами. Подключение пакета из pub.dev.Статические поля для счётчика ID.
5. 1) Поля класса принадлежит объекту, у каждого объекта своё значение. Переменная в функции существует только во время её выполнения и снаружи недоступна.
2) Конструктор — специальный метод, который вызывается при создании объекта.Дает начальное значение полей
3) @override говорит компилятору, что метод переопределяет метод родителя (у toString родитель — Object). Компилятор проверит, что такой метод есть, и защитит от опечаток в имени. Если убрать продолжит работать, но не сообщит об ошибках.
4) Обычные поля принадлежат каждому объекту отдельно.Статическое поле принадлежит классу целиком и существует
в одном экземпляре.
5) _counter — в Dart _ делает идентификатор приватным для файла, а не для
класса.
